What this room simulates

Controlling a computer by voice. Students with limited hand movement, chronic pain, fatigue or an injury often use voice control, saying the name of a button to click it. That only works when every button has a clear, unique name.

In this room we’ve deliberately blocked the mouse, scrambled the keyboard order and given most buttons vague, repeated names like “Click here”.

Hint: Mouse navigation is blocked. Keyboard tab order is scrambled. The clean path is voice control — enable Windows Voice Access (Settings → Accessibility → Speech) or macOS Voice Control (System Settings → Accessibility → Voice Control), then say “Click” along with the name of the button you wish to select. If a number appears on the screen, say it as well. No voice software? You can still Tab through all 12 controls to find it — it’ll just take a while.
I can’t work this out — show me how

How to solve it

  1. Turn on voice control. On a Mac: System Settings → Accessibility → Voice Control. On Windows 11: Settings → Accessibility → Speech → Voice access.
  2. Look for the one button with a specific, unique name: Reveal final code, in the Archive section.
  3. Say “Click Reveal final code”. If numbers appear on screen, say the number shown next to the button.

No voice control? Press Tab one step at a time (about ten presses) until Reveal final code is outlined, then press Enter. Notice how the outline jumps around the page in an order that makes no sense.

Why this matters for students

Try saying “Click Click here” — there are three of them, so voice software has to stop and ask which one you meant. For a student who uses voice all day, every vague or repeated label means extra commands and extra time. Across a whole course, pages like this become exhausting.
