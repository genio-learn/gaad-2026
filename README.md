# Genio + GAAD 2026
This repo contains a challenge that will sent out to celebrate GAAD 2026 at Genio. The challenge is a 5 page website where participants need to use assistive technology to gather clues to a password.

The pacticipants that complete it will be able to submit their name and answer to a Google Form which will deposit the details in a Google Sheet.

This was all vibe coded so... yeah...

## Deployment
This repo contains a [GitHub Action](https://github.com/genio-learn/gaad-2026/blob/main/.github/workflows/deploy.yml) which run on commits to `main` and deploys changes to GitHub Pages with the live version at [genio-learn.github.io/gaad-2026](https://genio-learn.github.io/gaad-2026/).

## Building
To build and run this website locally you can use the included NPM scripts like so;

```sh
# Install dependencies
npm install

# Start web server, changes are served on refresh (use npm run dev for live-reload)
npm start   # Serves under http://localhost:3000
```
